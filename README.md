## 🚀 Featured Projects

### 1. Employee Management System ([`miniproject.py`](miniproject.py))
An interactive, console-based CRUD application implementing Object-Oriented Programming principles:
- **Add Employee**: Create new employee profiles with unique ID, name, department, and salary.
- **View Records**: Display formatted details of all employees.
- **Search Employee**: Look up employees by ID.
- **Update Salary**: Modify existing employee compensation with input validation.
- **Delete Employee**: Remove records securely.

### 2. AI Text Processor ([`ai_pro/`](ai_pro/))
A modular package demonstrating Python package structure and separation of concerns:
- **Cleaner (`app/cleaner.py`)**: Sanitizes and normalizes irregular whitespace.
- **Analyzer (`app/analyzer.py`)**: Computes analytical metrics like word count.

## 🛠️ Getting Started

### Prerequisites
- Python 3.8 or higher installed on your system.

### Installation
Clone the repository to your local machine:
```bash
git clone https://github.com/Riya18code/Python_Code.git
cd Python_Code
```

### Running Programs
Run any script directly using Python:

```bash
# Run the Employee Management System
python miniproject.py

# Run the AI Text Processor package
python ai_pro/main.py

# Run individual topic scripts
python inheritance.py
python recursion.py
```
